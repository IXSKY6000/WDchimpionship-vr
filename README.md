# World Driver Championship — Android experimental download

Download `wdc-android-experimental.apk` from this branch and install it with SideQuest.

This is an experimental flat-screen Android ARM64 build. OpenXR, stereo rendering and head tracking are not implemented. Launch and rendering on a physical Quest have not been tested.

Import your own verified USA ROM in the app and use a Bluetooth gamepad. No ROM is included.

The corresponding port sources, patches, pinned dependency references and build instructions are in `WDchimpionship-vr-sources.zip`. See the included GPL-3.0 license and dependency notices. Base: https://github.com/alondero/worlddriverchampionship-recomp at 344391a06cd0364f51f3318f65584181f8397b3a.

SHA-256 checksums are recorded in `SHA256SUMS`.
